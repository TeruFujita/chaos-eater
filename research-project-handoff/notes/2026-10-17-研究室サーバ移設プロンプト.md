# なぜサーバに移すか
- 個人ノートPCは約 16GB RAM。公式構成は Docker Desktop → 入れ子 Docker（sandbox）→ kind → 題材。
- nginx はこの構成で公式完走できた。sock-shop はサービス多数で、AI の前（Phase 0 デプロイ）で基盤が落ちる。
- 他アプリをほとんど開いていなくても落ちる。足りないのは GPU ではなくシステム RAM と入れ子 Docker の重さ。
- 見積り: 16GB では sock-shop 公式入れ子は厳しい。サーバ（より大きい RAM）に寄せる。
- 比較のため、nginx も sock-shop もできるだけ同じサーバ上で揃える（片方だけ手元、は避ける）。

# サーバでやりたいこと（優先順）— 一から
1. サーバに Docker（Linux 推奨）を用意
2. リポジトリを clone（research/pipeline-v0）し、make setup-sandbox（または環境に合う setup-standard）。個人PCのコンテナや kind は引き継がない
3. OpenAI キーをサーバの docker/.env 等に設定（gpt-4o-2024-08-06）
4. 手元から SSH ポート転送:
   ssh <server> -L 3000:localhost:3000 -L 8000:localhost:8000 -L 2333:localhost:2333
   手元ブラウザで http://localhost:3000
5. 公式 GUI で実験（すべて新規実行。個人PCジョブの続きではない）:
